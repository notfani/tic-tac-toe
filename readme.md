# Tic-tac-toe Game (Крестики-нолики)

Это учебный проект на языке Go. Дополнение проекта будет после прохождения каждой главы книги.

## В ходе проекта будут затронуты:
- Написание кода в нескольких стилях (объектно-ориентированный, процедурный).
- Выделение повторяющегося кода в отдельные функции и пакеты, делая приложение более модульным и поддерживаемым.
- Добавление в готовый код новых функций и возможностей.
- Рефакторинг кода для улучшения его структуры и читаемости.
- Работа с файловой системой и СУБД (SQLite) с GORM.
- Проектирование интерфейсов и применение принципов инверсии зависимостей.
- Использование горутин и каналов для распределения вычислений и обработки данных.
- Организация взаимодействия по сети, реализация клиент-серверного приложения на TCP.
- Проектирование протокола обмена сообщениями между клиентом и сервером.
- Работа с базами данных в конкурентной среде, обеспечение безопасности и целостности данных.
- Декомпозиция проект на логические пакеты (board, game, player, network, room, db)
